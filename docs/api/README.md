# HTTP API Gateway

Здесь находятся [OpenAPI/Swagger спецификация](swagger.yaml), JSON-версия
и сгенерированный Go-файл. После запуска стека интерактивная документация
доступна по адресу `http://localhost:3000/swagger/index.html`.

Описание маршрутов — в [README Gateway](../../README.md),
архитектура и схема Redis — в [диаграммах](../README.md).
